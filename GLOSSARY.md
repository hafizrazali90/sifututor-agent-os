# Glossary

The words we use, and the words we do not. Every line is a correction Hafiz made
or a decision he took, so everyone and every agent says the same thing. Use
these in chat, issues, pull requests, review pages, staff messages, copy and
screens.

This file holds words and their meaning only. It holds no table names, field
names or code. If a term is unclear, ask Hafiz and add it here once he answers.

| Term | Say | Do not say | Notes |
| --- | --- | --- | --- |
| Tutor Request | **Tutor Request**, then **Request** after the first mention | "class", "this class already exists" | The arrangement record: parent, child, subject, mode, schedule, package. Corrected 03/10/2026. |
| class | **class**, only for one lesson | a Tutor Request | A single lesson inside a Tutor Request: first class, class time, classes per month. |
| Sifututor | **Sifututor**, the full brand name | "Sifu" on its own, in copy, merchandise or screens | "cikgu" is allowed as a brand-free word. Corrected 13/07/2026. |
| Nakngaji | **Nakngaji**, one word | "Naik Ngaji", or splitting or expanding it | Corrected 28/07/2026. |
| Kelasapp | **Kelasapp** for the product | "Kelas" as the product name | Lowercase "kelas" is the Malay word for class and is fine inside content, such as class names. Corrected 26/06/2026. |
| tutoring platform | **tutoring platform**, **platform** | "tuition business", "home tuition" as the category | Lead with finding the right tutor, not the venue. Corrected 13/07/2026 and 01/08/2026. |
| Area | **Area** or **Online** on tutor app request screens | the full street address, at any stage, even after the tutor is accepted | A family's address is private. Corrected 12/09/2026. |
| manual broadcast | **manual broadcast** for a broadcast sent by CX staff through the Finch staff tool | a catch-up wave sent by an agent | Name every send group by who sent it and what it was. Corrected 02/10/2026. |
| staging, live | **staging** for the test environment, **live** for production | "practice copy", "test kitchen" and other friendly names | Use the real system names. Corrected 30/09/2026. |
| duplicate | **duplicate**, only when every defining field matches | calling two Requests duplicates because they look alike | Compare class mode (online or physical), location, rate, schedule, students, subject and hours first. Corrected 03/10/2026. |
| SIMS in staff text | **SIMS** only where staff need it to understand what they see | "do it in SIMS" as a step, or "in SIMS" by habit | Ripple is where CRM staff work. State the fact; do not send staff back to SIMS. Corrected 01/10/2026 and 02/10/2026. |
| screen labels | the **ordinary word** other established apps use, such as "Edit" | an invented label such as "Ask us" | Check what other apps use before writing a label. Corrected 15/09/2026. |

## Adding a term

1. A correction or decision from Hafiz is the source. Write the date.
2. One line: the word to say, the word not to say, and one note.
3. If a word is only a code name, it does not belong here.
