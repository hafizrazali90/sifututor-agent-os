## 10. Areas requiring a pilot

| Area | Why a pilot rather than analysis |
| --- | --- |
| Strategy effectiveness | Which strategies work on which portfolios can only be learned by running them |
| Contact channel mix | Response rates by channel are portfolio-specific |
| Agent productivity | Real workload behaviour differs from modelled |
| Data quality in practice | Only visible when the data is actually worked |
| Integration reliability | Only proven under real volume |
| Conduct control effectiveness | Contact-window and frequency enforcement must be observed under load |
| Reconciliation friction | The most common source of dispute; must be exercised |
| Baseline validity | The pilot **produces** the baseline that any commercial model requires |
