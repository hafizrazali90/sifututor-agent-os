# Sifututor Ecosystem Reference-Style Prototype — Review Note

## Purpose

This four-slide prototype tests the supplied property-technology presentation's
graphic language with Sifututor content and brand colours before full-deck
production.

The prototype deliberately reproduces the reference's design behaviours:

- dominant human photography;
- flat editorial image collages;
- small interface and status overlays;
- rounded white evidence surfaces;
- compact capability grids;
- flat map and milestone modules;
- depth through overlap and scale rather than 3D rendering.

It does not copy the reference brand, logo, proprietary text, photographs or
business claims.

## Slides under review

1. **Hero collage** — authentic Sifututor human-learning photography, actual
   Ripple interface evidence and small service-context overlays.
2. **Operating context** — two generated Malaysian education-service scenes
   showing family coordination and operating responsibility.
3. **Connected solution** — actual Ripple interface in a flat browser frame
   with four distinct capability blocks.
4. **Milestones and expansion** — verified history, reusable-foundation
   framing, a flat Malaysia map and explicitly illustrative future verticals.
