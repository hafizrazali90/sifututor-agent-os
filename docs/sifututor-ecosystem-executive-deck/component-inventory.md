# Sifututor Ecosystem Executive Presentation — Component Inventory

This inventory defines the visual components that should be approved before the
full ecosystem executive presentation is produced. The component board uses
real Sifututor content and approved evidence so feedback applies directly to the
eventual deck rather than to generic stand-ins.

## Composition rule

The six groups share one brand system, but they must not share one repeated
card structure. The approved visual vocabulary includes open editorial space,
colour ribbons, asymmetric reading rails, image-led crops, milestone lines,
system constellations, connected service paths, circular nodes, directional
bands and full-bleed section moments. Rectangular containers remain available
for real interface evidence, tables and content that genuinely needs a frame.

## 1. Brand foundations

- Primary and supporting colour tokens.
- Display, body, editorial-accent and data-label typography roles.
- Logo placement and clear-space treatment.
- 1920×1080 stage, twelve-column layout and safe margins.
- Flat 2D composition, border, line and restrained depth rules.
- Professional-to-expressive balance.

## 2. Text and narrative hierarchy

- Section kicker or eyebrow.
- Assertion-led slide title.
- Controlled highlighted phrase.
- Supporting summary paragraph.
- Editorial principle or pull quote.
- Compact annotation and evidence caption.
- Source note, slide number and section label.

## 3. Evidence and imagery

- Actual-interface evidence frame.
- Human-outcome photography frame.
- Prototype evidence frame and mandatory status label.
- Screenshot title and system ownership label.
- Privacy-reviewed evidence note.
- Current capability, prototype and future-direction status badges.

## 4. Information blocks

- Milestone event and connected timeline.
- Proof chip.
- Metric or large-number component.
- System capability tile.
- Evidence callout.
- Comparison pair.
- Compact note or qualification.

## 5. Ecosystem and process relationships

- Operating-stage card.
- Directional connector and return loop.
- Authoritative core versus specialised system distinction.
- System-to-business-value relationship.
- Current capability versus future optionality treatment.
- End-to-end service journey composition.

## 6. Roadmap and presentation patterns

- Roadmap horizon card without volatile progress percentages.
- Dependency or enabling-foundation marker.
- Section-divider composition.
- Dense reading-first slide header.
- Speaker-led assertion slide.
- Closing message and discussion prompt.
- Navigation, progress, print and reduced-motion behavior.

## Review questions

1. Does the palette feel recognisably Sifututor and sufficiently professional?
2. Is the headline style confident without becoming promotional or playful?
3. Are human imagery and system evidence balanced correctly?
4. Are current, prototype and future states unmistakably different?
5. Do milestone, process and roadmap components look credible for stakeholders?
6. Is the density appropriate for an internal executive presentation and
   leave-behind document?

## Boundary

Approval of this component system authorises its use in the full presentation.
It does not approve new factual claims, publication, external distribution or a
final PDF. Those remain separate document-production and acceptance steps.
