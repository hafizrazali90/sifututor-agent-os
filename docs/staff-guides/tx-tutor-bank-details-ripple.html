Open Bank Accounts

TX operating instruction

Adding or updating a tutor’s bank details

Use Ripple’s Bank Accounts page to record the bank account used for a tutor’s payout.

Last updated: 3 August 2026 · Internal use only

!
The main rule

For tutor payout bank details, use Ripple → Tutor Payments → Bank Accounts. Do not update the bank fields in SIMS → Edit Tutor for this task.

Short version

Follow these four checks every time. The detailed instructions are below.

1

Open Bank Accounts

Go to Tutor Payments, then select Bank Accounts.

2

Search first

Search using the tutor’s name or Tutor ID to avoid duplicates.

3

Add or edit

Edit the existing record. Use Add New only when no record exists.

4

Check and save

Re-check the tutor, bank and account number before saving.

Production feature

Ripple → Tutor Payments → Bank Accounts

https://ripple.admin.sifututor.my/tutor-payments/bank-accounts

Open feature

Add bank details for the first time

Use this only when the tutor does not already have a bank account record in Ripple.

1

Find the tutor before adding anything

On Bank Accounts, search by tutor name or Tutor ID, for example TUT-123456.

If a record appears: do not use Add New. Follow the update instructions in the next section.
2

Select Add New

The Add Bank Details form will open.

3

Complete the form carefully

  • Tutor: choose the correct tutor and confirm the Tutor ID.
  • Account Holder Name: enter the full name as shown on the bank account.
  • Bank: select the tutor’s bank.
  • Account Number: ask the tutor to re-check every digit.
  • ID Type and ID Number: enter the correct identification details.
4

Select Add and confirm success

When Ripple shows “Bank details added”, search for the tutor again and confirm the record is listed.

Update an existing bank account

Use this when a tutor changes their bank, account number or account-holder details.

1

Search for the existing record

Use the tutor’s name or Tutor ID. Confirm that the name and Tutor ID match the tutor who requested the change.

2

Open Edit on that tutor’s row

Do not create a second record for the same tutor.

3

Change only the confirmed details

If the account number is changing, type the new number and ask the tutor to re-check it. If the number is not changing, leave that field blank so Ripple keeps the current number.

4

Select Save and confirm success

When Ripple shows “Bank details updated”, search again and check that the tutor’s record is still present.

Before you save

Bank information is sensitive and a wrong digit can send a payout to the wrong account.

✓ Do

  • Verify the tutor’s full name and Tutor ID.
  • Use the account-holder name exactly as shown by the bank.
  • Ask the tutor to re-check the account number digits.
  • Save payout bank details in Ripple Bank Accounts only.
  • Keep all bank information private.

× Don’t

  • Do not update SIMS Edit Tutor bank fields for a payout.
  • Do not add a second record when the tutor already exists.
  • Do not use Import CSV unless Accounts or an admin instructs you.
  • Do not share account numbers in group chats or screenshots.
  • Do not remove a record unless Finance or Accounts instructs you.
🔒

Protect the tutor’s bank information

Never place a full account number in a group chat, ticket title or public screenshot. If you need to report an error, share the Tutor ID and the error message, and hide the account number in any screenshot.

If something is not working

Try the matching instruction below. Avoid pressing Add or Save repeatedly because that may create confusion or duplicate work.

Bank Accounts or Add New is missing

Ask your team lead or Ripple admin to check that your Staff access includes both View Payment Slips and Edit Bank Details. After access is changed, log out of Ripple and log in again.

The tutor cannot be found

Check the spelling and use the correct Tutor ID. Confirm that the tutor profile exists in SIMS. If the tutor still does not appear, send the Tutor ID to your team lead.

Ripple rejects the account number

Check that it contains only digits or dashes and is between 5 and 20 characters. Also select a supported bank and complete the account-holder name.

The tutor still shows “Missing Bank” during payment review

Open Ripple → Tutor Payments → Review & Approve and refresh the page. If the warning remains, confirm that the correct tutor record was updated.

A save or network error appears

Do not keep creating new records. Take a screenshot with the account number hidden, then send the Tutor ID and error message to your team lead or Ripple admin.

Who does what?

TX collects, checks and enters the tutor’s bank details. Finance or Accounts uses the record for payment processing and approval. TX should not use other Tutor Payments actions unless specifically assigned.
