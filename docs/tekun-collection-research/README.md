## 1. Purpose

This pack is the evidence base for a possible future stakeholder document about a
proposed collection partnership with **TEKUN Corporation Sdn Bhd** (TCorp).

It exists so that whoever writes that document later can:

- describe TEKUN Corporation accurately, without confusing it with TEKUN Nasional;
- separate the organisations that **hire** TEKUN Corporation from any provider
  TEKUN Corporation might **hire**;
- state current Malaysian collection regulation correctly as at 31 August 2026;
- design platform capability, performance measures and commercial options on
  evidence rather than assumption;
- ask TEKUN Corporation the right questions instead of guessing the answers.

**This pack deliberately does not** write the proposal, decide pricing, claim
legal compliance, or assert facts that public sources do not support.

## 4. How future agents should use this pack

1. **Start with [research-handback.md](research-handback.md).** It states the
   strongest conclusions and the single next action.
2. **Never restate a claim without checking [claim-register.md](claim-register.md).**
   Each claim carries a status. A claim marked `Interpretation` must not be
   written as a verified fact.
3. **Respect the entity boundary.** TEKUN Corporation Sdn Bhd and TEKUN Nasional
   are different legal entities with different mandates. Findings about one are
   never automatically true of the other.
4. **Respect the relationship boundary.** The ~30 organisations named publicly are
   TEKUN Corporation's **clients** (they appointed TCorp to collect for them).
   They are not TCorp's suppliers. See
   [current-third-party-and-commercial-model.md](current-third-party-and-commercial-model.md).
5. **Do not fill gaps with benchmarks.** Where TEKUN's own figures are unknown,
   the pack says so. An industry benchmark may be cited, but only labelled as a
   benchmark and never as TEKUN's rate.
6. **Reverify volatile claims before publishing anything.** See §6.

## 5. Evidence classifications

### Reader-facing status of a claim

| Status | Meaning |
| --- | --- |
| **Verified fact** | Supported by a primary or authoritative source that was opened and read |
| **Interpretation** | Our reasoned conclusion drawn from evidence; not itself a source statement |
| **Proposed direction** | Owner-confirmed intent for the partnership; not a current capability |
| **Illustrative option** | A possible example or archetype, not a commitment or a recommendation |

### Confidence in a factual finding

| Confidence | Meaning |
| --- | --- |
| **Confirmed** | Supported by an authoritative primary source |
| **Strongly indicated** | Multiple credible sources agree, but the underlying document was not seen |
| **Unconfirmed** | Found only in weak or indirect evidence |
| **Not publicly disclosed** | Searched, and no reliable public evidence was found |
| **Contradictory** | Reliable sources disagree |
| **Requires TEKUN confirmation** | Cannot be responsibly determined from public information |

**"Not publicly disclosed" is a finding, not a licence to guess.** A missing
contract does not permit inferring its contents.

## 6. Freshness rules

This subject is time-sensitive. Malaysia's Consumer Credit Act 2025 regime
became operative during 2026. For an existing affected operator, section 135(1)
requires an application within six months from 1 June 2026. The exact deadline,
applicability and application status must be confirmed before external use.

| Claim type | Reverify |
| --- | --- |
| Consumer Credit Act commencement, transition provisions and SKP standards | Before any external use, and at minimum monthly until 31 December 2026 |
| SKP fees, thresholds, subsidiary legislation | Before any commercial or pricing discussion |
| TEKUN Corporation client list and named appointments | Before any external use |
| PDPA guidelines and circulars | Before any data-handling commitment |
| Third-party provider status | Before any incumbent or transition statement |
| Platform vendor capability claims | Before any comparison is published |

Any claim in [claim-register.md](claim-register.md) whose freshness rule has
lapsed must be treated as unverified until reopened.

## 7. Disclaimers

- **Not legal advice.** Nothing here states that TEKUN Corporation, Sifututor, or
  any party is or would be compliant with any law. Statements about legal
  applicability are flagged as requiring confirmation with TEKUN Corporation's
  compliance function and qualified Malaysian legal counsel.
- **Not a commercial offer.** Commercial models are archetypes for discussion.
  No rate here is a quote, and none should be presented as TEKUN's current rate.
- **No claim of an existing relationship.** TEKUN Corporation is a *prospective*
  client. Nothing in this pack should be read or written as saying TEKUN already
  uses our system.
- **No performance guarantee.** Improved collection is described as a measurable
  pathway, not a promise of profit.
- **Public sources only.** No credentials, private databases, leaked documents or
  non-public personal data were used.
- **Terminology.** Repayable accounts are called *financing recipients* or
  *customers in arrears*. They are not called "grant recipients".
