# Out Of Scope

A record of ideas we looked at and decided not to do. Read it before proposing
a new tool, rule, skill or process, so the same debate does not run twice.

## The rule

We add a rule, tool or process only after we have **seen it fail in our own
work**. A good idea from somewhere else, or a rule that would be nice to have,
is not enough. If there is no observed failure, the answer is "not now", and the
idea goes here with the reason.

## One file per idea

Name the file after the idea, in lowercase with hyphens. Each file has exactly
these headings:

- `# Title`: the idea in a few words.
- `## What was proposed`: what it is and where it came from.
- `## Why it is out of scope`: the reasons, with the evidence.
- `## What would change our mind`: the observed failure or change that would
  reopen it.
- `## Decided`: the date (DD/MM/YYYY, MYT) and who decided.

## Before you add a file

Search this folder and `docs/decisions/` first. If the idea is already here,
link to it instead of writing a second file. If the idea is accepted instead,
it belongs in `docs/decisions/` or in the owning playbook.
